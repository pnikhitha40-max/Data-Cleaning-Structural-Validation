# Data Cleaning & Structural Validation

## Project Overview

This project demonstrates a complete data cleaning pipeline using Python and Pandas.

## Features

- Remove duplicate rows
- Handle missing values
- Validate email addresses
- Standardize phone numbers
- Convert dates to YYYY-MM-DD
- Validate age values
- Generate data quality report

## Technologies

- Python
- Pandas
- NumPy
- Regular Expressions

## Folder Structure

```
data/
output/
data_cleaning.py
requirements.txt
README.md
```

## Run

```bash
pip install -r requirements.txt
python data_cleaning.py
```
